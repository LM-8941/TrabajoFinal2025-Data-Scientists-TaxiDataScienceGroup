# Project Charter: TrabajoFinal2025 — Data Science : TaxiDataScienceGroup

## 1. Objetivo del negocio
Optimizar la distribución de la flota mediante la identificación de patrones de demanda por zona y por hora, mejorando la eficiencia operativa, reduciendo tiempos de espera y aumentando el número total de viajes atendidos.

## 2. Objetivo de Data Science
Desarrollar un pipeline ETL escalable que procese grandes volúmenes de datos y genere información accionable sobre la demanda de taxis.

## 3. Alcance del Proyecto
✔ ETL Completo
    Extracción de datos desde AWS S3
    Limpieza de datos
    Transformaciones clave
✔ Análisis y Métricas
🚫 Construcción de un modelo de predicción avanzado.
🚫 Implementación de un sistema de asignación automática de taxis.
